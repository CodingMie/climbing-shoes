现有 UI · 保留

  • 信息架构与全部路由、页面职责不变

现有 UI · 替换

  • Inter + 纯中性灰 token → Space Grotesk / IBM Plex Mono / Noto Sans SC + 山系色板
  • 圆角卡片 + shadow-sm 堆叠 → hairline 细线分组、统一 2px 直角、无阴影
  • 居中 hero → 左对齐非对称 hero + 数据条

落地说明 · 实现约束

不动：路由、数据获取、server actions、zod / DB schema；E2E 依赖的按钮文字、表单标签、role="alert"、空态文案。

改动层：globals.css token（oklch 山系色板 + 2px radius）、layout.tsx 字体（Space Grotesk / IBM Plex Mono / Noto Sans SC，next/font 自托管）、site-header、review-card、各页面视觉层。

新增依赖：@phosphor-icons/react（统一 strokeWidth 1.5，替换设计稿中的占位 SVG）。

需真图清单：① 鞋库卡片主图（4:3，每款鞋 1 张）② 鞋详情页主图（4:3，可多张）③ 首页若无数据时的空态插图（可选，线性山形风格）。当前以标注占位槽呈现。

E2E 适配：测评卡片不再展示 rating 条与尺码偏移（综合分数字保留）；维度均分雷达图配 sr-only 七维列表（li，含综合推荐指数）；合身度反馈保留 section / h4 / li 语义（每部位一个 section，选项为 li），确保 aggregates.spec 的定位器不变。

验收：bun run typecheck · bun run lint · bun run test:e2e 全绿；WCAG AA 对比度（accent #C2410C 对白 4.8:1）。
